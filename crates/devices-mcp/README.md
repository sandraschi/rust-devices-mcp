# devices-mcp (L2)

CLI-first binary + MCP stdio server. One binary, two faces: humans get flags,
agents get `--json` or full MCP tools — all powered by the same
`devices_core::dispatch`, so the two surfaces can never disagree.

## The deal

- **Dependencies:** `devices-core` + `clap` + `serde`/`serde_json`. No `rmcp`
  in v0.1 (deliberate — see root README's rmcp note). Builds offline from the
  local registry cache.
- **Stdio invariant:** stdout is pure JSON-RPC. The only `eprintln!` in the
  binary is the startup line. Audit for rogue `println!` before every release.
- Same never-crash lints as L1. `writeln!(...).ok()` + `let ... else` patterns
  keep the framing loop infallible.

## CLI

```text
rust-devices-mcp status [--json]
rust-devices-mcp plug-stats --device-ip <IP> [--json]
rust-devices-mcp plug-toggle --device-ip <IP> --state <true|false> [--json]
rust-devices-mcp camera-describe --device-ip <IP> [--json]
rust-devices-mcp camera-snapshot --device-ip <IP> [--json]
rust-devices-mcp mcp
```

## MCP (2024-11-05, hand-rolled framing)

`tools/list` is generated by the pure, unit-tested `tools_list()` function;
`tools/call` routes through the pure `call_tool(name, args)` into `dispatch`.
Purity matters: both are testable without sockets, stdio, or hardware.

| Method | Behavior |
|---|---|
| `initialize` | `protocolVersion 2024-11-05` + server info |
| `tools/list` | 5 tools with JSON Schemas (`status`, `plug.get_stats`, `plug.toggle`, `camera.describe`, `camera.snapshot_meta`) |
| `tools/call` | dispatches by name; unknown tools become error *content*, not transport errors |
| `ping` | `{}` |
| notifications (no `id`) | no reply, by spec |
| unknown methods | `-32601`; unparseable frames → `-32700` |

Missing args default safely (`device_ip` → `""` becomes an `invalid input`
error value; `state` → `false`) — hostile input degrades to JSON, never to a
crash. Probe:

```powershell
'{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}' | cargo run -q -p rust-devices-mcp -- mcp
```

## Tests

3 unit tests: catalog holds 5 tools, unknown tool → error content, missing
`state` defaults without panic. Plus the live stdio probe in CI-by-hand
(see root README verification). Run: `cargo test -p rust-devices-mcp`.
